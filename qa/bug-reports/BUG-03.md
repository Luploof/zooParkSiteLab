# BUG-03: PDF билета не создаётся при запуске приложения не из корня проекта

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | High                                                         |
| Priority  | Medium                                                       |
| Модуль    | Покупка билетов / окружение                                  |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Доступны исходники проекта и Gradle.
- Есть тестовый пользователь для входа.

## Шаги воспроизведения

1. Собрать приложение командой `./gradlew bootJar`.
2. Запустить `java -jar build/libs/zooPark-0.0.1-SNAPSHOT.jar` из папки `build`.
3. Войти в систему и купить любой билет.

## Ожидаемый результат

PDF билета создаётся независимо от папки, из которой запущено приложение.

## Фактический результат

По исходному описанию дефекта возвращается ошибка 500: файл `src/main/resources/arialmt.ttf` не найден. Заголовки PDF уже отправлены, поэтому ответ повреждён. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: шрифт читается по относительному пути к файлу, который существует только в исходниках.
