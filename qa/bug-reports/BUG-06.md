# BUG-06: Повторная регистрация с существующим email приводит к ошибке 500

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | High                                                         |
| Priority  | High                                                         |
| Модуль    | Регистрация                                                  |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь `test1@gmail.com` уже зарегистрирован.
- Открыта страница `/register`.

## Шаги воспроизведения

1. Заполнить форму регистрации, указав email `test1@gmail.com`.
2. Нажать «Зарегистрироваться».

## Ожидаемый результат

Показано сообщение «Пользователь с таким email уже существует», форма остаётся на странице.

## Фактический результат

По исходному описанию дефекта отображается страница ошибки 500 (исключение уникального индекса `users.email`). Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: `UserService.register` не проверяет существование email, исключение БД не обрабатывается.
