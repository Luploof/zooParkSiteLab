# BUG-01: Неизвестный тип билета принимается при покупке

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | High                                                         |
| Priority  | High                                                         |
| Модуль    | Покупка билетов                                              |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь авторизован.
- Открыта страница `/tickets`.

## Шаги воспроизведения

1. Открыть DevTools браузера и перейти к элементу выбора типа билета.
2. Изменить значение одного из вариантов на `abc`.
3. Выбрать изменённый вариант, указать количество `1` и отправить форму покупки.

## Ожидаемый результат

Сервер отклоняет неизвестный тип билета: возвращает ошибку валидации (например, HTTP 400) или показывает понятное сообщение. PDF билета не формируется.

## Фактический результат

По исходному описанию дефекта сервер формирует `ticket.pdf` с типом «Неизвестный» и стоимостью `0.00 BYN`. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: ветка `default` в обработке типа билета назначает название «Неизвестный» и цену `0`, вместо того чтобы отклонить недопустимое значение.
