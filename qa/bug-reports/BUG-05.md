# BUG-05: Заявка на экскурсию принимается без проверки данных, сбой отправки возвращает код 200

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Экскурсии                                                    |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь авторизован.
- Открыта страница `/excursions`.
- Для проверки сбоя отправки есть возможность указать неверный пароль SMTP.

## Шаги воспроизведения

1. В DevTools изменить данные формы: количество `0`, `-2`, `9999`; название экскурсии `abc`; email `abc`.
2. Отправить заявку с каждым из этих значений.
3. Отдельно: указать неверный пароль SMTP, отправить корректную заявку и посмотреть код ответа во вкладке Network.

## Ожидаемый результат

Некорректные данные отклоняются с кодом 400; при сбое отправки возвращается код 500.

## Фактический результат

По исходному описанию дефекта письмо администратору отправляется с любыми значениями; при сбое SMTP ответ имеет код 200 и текст `error`. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: параметры не валидируются, метод всегда возвращает строку (HTTP 200).
