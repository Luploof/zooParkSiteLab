# BUG-07: Регистрация выполняется без проверки email, пароля и имени

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Регистрация                                                  |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Открыта страница `/register`.

## Шаги воспроизведения

1. В DevTools удалить атрибуты `required` у полей формы.
2. Заполнить форму: email `abc`, пустое имя, пароль из одного символа.
3. Отправить форму.

## Ожидаемый результат

Показана ошибка валидации, пользователь не создаётся.

## Фактический результат

По исходному описанию дефекта пользователь создаётся с любыми значениями, включая пустые. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: параметры `@RequestParam String` проверяют только наличие значения, а не его содержимое; `spring-boot-starter-validation` подключён, но не используется.
