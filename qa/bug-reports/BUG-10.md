# BUG-10: Несуществующий id животного приводит к ошибке 500

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Животные                                                     |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь авторизован.
- Животного с id `9999` в базе нет.

## Шаги воспроизведения

1. Открыть страницу `/animals/9999`.

## Ожидаемый результат

Возвращается страница с кодом 404.

## Фактический результат

По исходному описанию дефекта возвращается ошибка 500 (шаблон получает `null`). Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: `getAnimalById` возвращает `null`, и контроллер передаёт его в шаблон.
