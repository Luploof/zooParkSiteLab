# BUG-09: Опыт длиннее 1000 символов в заявке волонтёра приводит к ошибке сохранения

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Волонтёры                                                    |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Открыта страница `/volunteers`.

## Шаги воспроизведения

1. Заполнить форму заявки волонтёра.
2. В поле опыта вставить текст длиннее 1000 символов.
3. Отправить форму.

## Ожидаемый результат

Показано сообщение о слишком длинном тексте.

## Фактический результат

По исходному описанию дефекта показывается ошибка сохранения. В заголовке исходного описания также упомянуто, что после ошибки пропадает статистика; этот пункт нужно уточнить. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: длина опыта не проверяется (колонка в БД ограничена 1000 символами).
