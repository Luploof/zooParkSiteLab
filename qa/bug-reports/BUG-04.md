# BUG-04: В письме администратору о заявке на экскурсию перепутаны поля

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Экскурсии                                                    |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь авторизован.
- Открыта страница `/excursions`.
- Есть доступ к почте администратора.

## Шаги воспроизведения

1. Заказать любую экскурсию, указав имя и email.
2. Открыть письмо, полученное администратором.

## Ожидаемый результат

Тема письма «Новая заявка на экскурсию»; в тексте указаны имя пользователя, его email, экскурсия и количество человек.

## Фактический результат

По исходному описанию дефекта в письме указано «Имя: <адрес администратора>», «Email: Новый заказ!», «Сообщение: Пользователь ...». Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: метод `sendOrder(name, email, text)` вызывается как `sendOrder(adminEmail, "Новый заказ!", text)`, то есть аргументы не соответствуют параметрам.
