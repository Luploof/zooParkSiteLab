# BUG-02: Недопустимое количество билетов принимается при покупке

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | High                                                         |
| Priority  | High                                                         |
| Модуль    | Покупка билетов                                              |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь авторизован.
- Открыта страница `/tickets`.

## Шаги воспроизведения

1. В DevTools убрать у поля количества ограничение `min`.
2. Ввести значение `0` и отправить форму; повторить для `-3` и `1000000`.

## Ожидаемый результат

Сервер отклоняет значения вне допустимого диапазона 1-50 (принятое требование). PDF билета не формируется.

## Фактический результат

По исходному описанию дефекта сервер формирует PDF со стоимостью `0.00 BYN`, отрицательной суммой (например, `-60.00 BYN`) или очень большой суммой. Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: количество не проверяется на сервере, итоговая стоимость считается как `price * quantity`.
