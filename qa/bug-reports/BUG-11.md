# BUG-11: Статические ресурсы недоступны неавторизованным пользователям

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Low                                                          |
| Priority  | Medium                                                       |
| Модуль    | Безопасность / интерфейс                                     |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Пользователь не авторизован (выполнен выход из аккаунта).

## Шаги воспроизведения

1. Открыть страницы `/`, `/login` и `/register`.
2. Во вкладке Network посмотреть запросы к `/images/...` и `/js/...`.

## Ожидаемый результат

Статические ресурсы загружаются без входа в систему.

## Фактический результат

По исходному описанию дефекта запросы перенаправляются на `/login` (HTTP 302), изображения не отображаются (зависит от шаблонов, нужно проверить). Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: в `permitAll` указан только `/css/**`, остальные ресурсы требуют входа.
