# BUG-08: Заявка волонтёра без выбранных интересов приводит к странице ошибки 400

| Поле      | Значение                                                     |
| --------- | ------------------------------------------------------------ |
| Severity  | Medium                                                       |
| Priority  | Medium                                                       |
| Модуль    | Волонтёры                                                    |
| Окружение | Windows 10/11, Chrome, Java 21, Spring Boot 3.5.5, MySQL 8.0 |
| Статус    | New                                                          |

## Предусловия

- Открыта страница `/volunteers`.

## Шаги воспроизведения

1. Заполнить форму заявки волонтёра, не отмечая ни одной области интересов.
2. Отправить форму.

## Ожидаемый результат

Показано сообщение «Выберите хотя бы одну область интересов», форма остаётся на странице.

## Фактический результат

По исходному описанию дефекта отображается страница ошибки 400 (отсутствует обязательный параметр `interests`). Результат необходимо подтвердить повторным запуском на исходной версии приложения.

## Технические заметки

Предполагаемая причина по анализу кода: параметр `interests` обязателен на уровне Spring, поэтому проверка срабатывает до вызова метода контроллера.
