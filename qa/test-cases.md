# Тест-кейсы

Объект тестирования: сайт зоопарка «Зелёный Мир» (Spring Boot, Freemarker, MySQL).
Техники тест-дизайна: эквивалентное разбиение, анализ граничных значений, негативное тестирование.

**Столбцы результата:** `v1` - прогон на исходной версии (до исправлений), `v2` - повторная проверка после исправлений.
Предусловие для всех кейсов: сайт запущен на `http://localhost:8080`, выполнен вход под `test1@gmail.com`.

Всего тест-кейсов: **55**.
